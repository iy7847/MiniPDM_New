## ⚖️ 비즈니스 로직 규칙

### 단가 계산 (Scales.md 준수 필수)

```
단가 = 소재비 + 가공비 + 열처리비 + 후처리비 + 이익

소재비:   중량 × kg당단가
가공비:   가공시간 × 시간당임률 × 난이도계수
열처리비: 중량 × 열처리 kg당단가
후처리비: 중량 × 후처리 kg당단가

중량(사각): (가로 × 세로 × 두께 × 비중) / 1,000,000
중량(원형): (π × 반지름² × 길이 × 비중) / 1,000,000
```

### 난이도 계수
| A | B | C | D | E | F |
|---|---|---|---|---|---|
| 1.0 | 1.2 | 1.5 | 2.0 | 2.5 | 3.0 |

## 🤖 AI 에이전트 팀 구조 및 파이프라인 (필수 지침)

이 프로젝트는 메인 에이전트(PM)와 3명의 전문 서브 에이전트가 협력하여 구축합니다. 작업을 분담할 때 반드시 이 구조를 따르세요.

### 1. 🎨 UI/UX 엔지니어 (Subagent: `ui_engineer`)
- **역할**: `design-system/` 폴더 전담, 시각적 구현 및 UI 컴포넌트 구축
- **임무**: Tailwind 토큰 설정, 공통 UI 컴포넌트(Button, Card 등) 제작, 디자인 일관성 유지

### 2. 🧱 피처 & 레이아웃 개발자 (Subagent: `feature_dev`)
- **역할**: `features/`, `layout/`, `app/` 폴더 전담, 사용자 화면과 플로우 책임
- **임무**: UI 컴포넌트를 조립하여 실제 화면 구성, 라우팅, 인터랙션(드래그앤드롭 등) 처리

### 3. ⚙️ 데이터 & 백엔드 전문가 (Subagent: `data_engineer`)
- **역할**: `services/`, `shared/hooks/` 폴더 전담, 데이터 무결성과 비즈니스 로직 집중
- **임무**: Supabase 쿼리 작성, 복잡한 계산식(단가 계산 등) Hook 분리, 전역 상태 관리

### 협업 파이프라인 규칙
- **컴포넌트 우선**: `ui_engineer`가 먼저 기본 컴포넌트와 토큰을 만들면, 이를 바탕으로 `feature_dev`와 `data_engineer`가 화면과 데이터를 붙입니다.
- 메인 에이전트(PM)는 작업 지시, 코드 리뷰(DIRECTIVE 및 DESIGN 문서 준수 여부 검증)를 수행합니다.

### 👁️ 브라우저 시각적/기능적 검증 파이프라인 (PM 역할)
- 서브 에이전트가 UI 컴포넌트나 화면 개발을 완료했다고 보고하면, PM은 반드시 **`chrome-devtools` (MCP 서버)**를 사용하여 직접 검증합니다.
- 로컬 서버(`http://localhost:5173`)로 `navigate_page` 후, `take_screenshot` 도구를 활용하여 실제 렌더링된 화면(색상, 여백, 컴포넌트 배치 등)을 캡처하고 시각적으로 검수합니다.
- `click`, `type_text` 등을 통해 인터랙션을 확인하고, 에러 로그(`list_console_messages`)를 검토한 뒤 최종 머지를 승인합니다.
